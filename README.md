# Exercise 0: Using Chatbots for Statistical Work

Part of the workshop **AI-Powered Coding and Data Analysis**. This is the copy-and-paste chatbot demonstration in Module 2.

## Install packages

Run this once in the R console, from the project folder:

```r
source("setup.R")
```

It installs any missing packages used anywhere in the workshop: readr, dplyr, tidyr, ggplot2, broom, here, and rmarkdown. If you already ran it for another workshop project, you can skip this step.

## Run the demo

1. Open `yale-ai-stats-00-chat-demo.Rproj` in RStudio, or open this folder in Positron.
2. Open `notebooks/chat-demo.qmd` and run the chunk.
3. Copy the code into a chatbot and ask: "Can you help me visualize this?"
4. Paste the reply into a new chunk and run it.
